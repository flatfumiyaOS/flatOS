# 業務管理アプリ

リフォーム会社の現場監督・施工管理業務を支援する、ブラウザで動くシンプルなWebアプリです。
Python の Streamlit というツールで作られています。まずは「顧客データベース」画面から使えます。

## 起動方法（初回のみのセットアップは不要・毎回この2行だけ）

1. ターミナルでこのフォルダに移動する
   ```
   cd "/Users/arymaxflat238/Desktop/flat OS/業務管理アプリ"
   ```
2. 以下のコマンドを実行する
   ```
   source venv/bin/activate
   streamlit run app.py
   ```
3. 自動的にブラウザが開き、アプリが表示されます（開かない場合は表示されたURL、通常は http://localhost:8501 を開いてください）
4. 終了するときはターミナルで `Ctrl + C` を押してください

## できること（現状）

- 👥 顧客データベース
  - 顧客の新規登録（氏名・フリガナ・電話番号・メール・住所・備考）
  - 顧客の検索（氏名やフリガナ、電話番号などで絞り込み）
  - 顧客情報の編集・削除（削除は確認ボタンあり）
- 📋 見積書
  - Googleスプレッドシートの見積書を画面いっぱいに埋め込み、アプリ内で直接編集できます
  - 編集するには、表示されたシート内でGoogleアカウントにログインし、そのシートの編集権限を持っている必要があります
- 💬 チャット
  - どのページでも、右上の「💬 チャット」ボタンを押すと画面右側にAIチャットパネルが表示されます
  - Claude(Anthropic API)を利用するため、`.streamlit/secrets.toml` に `ANTHROPIC_API_KEY` の設定が必要です

## データの保存場所

顧客データは `data/customers.db` というファイル（SQLiteデータベース）に保存されます。
このファイルがアプリのデータ本体なので、誤って削除しないよう注意してください。
